# Images

Drop your real images into these folders. Nothing reads them yet: each set is
wired into the scene once it is in.

| Folder                  | What goes in it                         | Where it shows                                     |
| ----------------------- | --------------------------------------- | -------------------------------------------------- |
| `certificates/`         | certificate and award scans             | the framed certificates on the computer-desk shelf |
| `design/`               | graphic design work (posters, layouts)  | the poster wall above the computer desk            |
| `profile/`              | your portrait                           | the dossier's subject photo                        |
| `projects/development/` | screenshots of development projects     | the Development disks in the archive terminal      |
| `projects/ui-ux/`       | screenshots of UI/UX projects           | the UI/UX disks in the archive terminal            |
| `projects/video/`       | stills or thumbnails of video projects  | the Video Editing disks (clips go in `/videos`)    |
| `dossier/`              | (existing) the dossier's photo prints   | the dossier on the main desk                       |

WebP is best (small and sharp). Keep names short and in order, e.g. `1.webp`,
`2.webp`, so they can be listed from code without renaming.
