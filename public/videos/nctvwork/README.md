# NCTV Work PH videos

Web copies for the "NCTV Work PH" disk (Video Editing disk 1, `vid-1` in
src/data/projects.ts): 360x640 (the news is 854x480), H.264, no audio (the
terminal plays muted). Posters are in public/images/projects/video/nctvwork/.

The original exports are kept outside the site, in V:\case-404-video-masters\.
To add or replace a video: export it, make a web copy and a poster the same
way (V:\case-404-tmp\encode.cjs and posters.cjs), and add it to `videos` in
the project's record with its group and title.
