# Phase 2B.0 — Investigation board structure audit

Measured from the GLB (gltf-transform) and verified in the running scene by
hiding meshes group-by-group. Runtime names drop the dots
(`Plane.058__0` → `Plane058__0`) — use the runtime form in code.

**Totals:** 51 meshes, 20,700 tris, **1 material** (`Scene_-_Root`),
**3 textures, all 4096² PNG** (base 7.8 MB, normal 5.2 MB, metal/rough
10.3 MB). Runtime GLB 24.2 MB. All pieces share **one atlas**, but every
piece is its **own mesh with its own UV island** (no instancing).

| Piece                | Mesh(es)                                                          | Verified as                                          | Separate?                 |
| -------------------- | ----------------------------------------------------------------- | ---------------------------------------------------- | ------------------------- |
| Frame + cork backing | `Cube.099` (36 tris)                                              | one box; frame is painted in the atlas, not modelled | yes (single mesh)         |
| Central map          | `Plane.058` (70 tris, UV 0.42–0.67 × 0.11–0.49)                   | world map                                            | yes                       |
| Newspaper            | `Plane.062` (0.053 thick — bent)                                  | "Evening Chronicle" clipping                         | yes                       |
| Photos (10)          | `Plane.059, .060, .061, .063, .066, .067, .069, .070, .071, .072` | mugshots ×2, street/building photos ×8               | yes, each                 |
| Numbered notes (6)   | `Plane.064, .065, .068, .073, .074, .075`                         | `#1`–`#6` cards                                      | yes, each                 |
| Pushpins (28)        | `Cylinder.006`–`.035` (no `.028`/`.034`), 448 tris each           | red-head pins                                        | yes, each — not instanced |
| Red string (4)       | `BezierCurve`, `.001`, `.002`, `.003`                             | string between map pins                              | yes, each                 |

**Critical finding — baked shadows.** The cork/frame texture and the map
texture both have the shadows/AO of the pieces lying on them **baked in**.
Hiding any photo, note, or the map leaves a dark ghost shape behind
(verified: hiding the map leaves a large black rectangle on the cork).
Consequence: pieces can be **re-textured in place freely**, but **removing
or moving** any piece requires retouching the cork (and map) atlas.

**Replacement feasibility**

| Category       | Verdict                                                                                             |
| -------------- | --------------------------------------------------------------------------------------------------- |
| Frame + cork   | KEEP AS-IS                                                                                          |
| Pins           | KEEP AS-IS (independent transforms, positions known)                                                |
| Map            | REPLACE TEXTURE (own UV island; keep geometry — removing it exposes baked shadow)                   |
| Photos         | REPLACE TEXTURE per piece (own UV islands; keep geometry + pins)                                    |
| Numbered notes | REPLACE TEXTURE per piece                                                                           |
| Newspaper      | REPLACE TEXTURE (bent geometry, good for a clipping)                                                |
| Red string     | KEEP / HIDE selectively — strings sit above everything, hiding leaves no baked mark                 |
| Shared atlas   | SHARED ATLAS — a full replacement atlas is feasible since islands don't overlap the content regions |

**Performance:** HERO-acceptable but heavy. Pins are 12,544 of the 20,700
tris (61%) for ~1cm objects — the obvious decimation target. 51 draw calls
for one prop. ~85 MB GPU memory for the three 4096² maps with mipmaps. Not
optimized yet (analysis only).
