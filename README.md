# CASE 404

Portfolio of Vince Bryant Cabunilas, in two versions:

- `/`: the website (`index.html`, `src/site/`), plain HTML and CSS, no WebGL.
- `/3d/`: the immersive 3D detective's office (`3d/index.html`, `src/main.tsx`),
  linked from the website's "3D version" card.

See `ARCHITECTURE.md` for the technical source of truth and `DEVELOPMENT.md`
for development tooling.

```
npm install
npm run dev
```
